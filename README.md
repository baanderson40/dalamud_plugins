# Dalamud Plugins

## Plugins

### [Aetherial Eviction](https://github.com/baanderson40/Aetherial-Eviction)

Reduces resource pressure across multiple FFXIV clients:

- Trims the current client's Windows working set.
- Controls background rendering with combat and transition bypasses.
- Saves window placement across monitors.

### [Another Occult Crescent Helper](https://github.com/baanderson40/Another_Occult_Crescent_Helper)

Automates and monitors activities in Occult Crescent:

- Critical Engagement and FATE farming.
- Pot treasure and treasure hunting.
- Manual and automatic overworld coffer routes.
- Movement, combat, recovery, and dangerous-travel automation.
- Currency shopping and configuration, debug, dependency, and log tools.

### [GatherBuddyReborn](https://github.com/baanderson40/GatherBuddyReborn)

Personal development fork of GatherBuddyReborn:

- Gathering and resource-list management.
- Automated navigation through vnavmesh.
- Fork-specific changes maintained separately from upstream.

### [PlotWatch](https://github.com/baanderson40/PlotWatch)

Tracks housing plots and lottery schedules:

- Housing availability data through Paissa.
- Watched-plot tracking and plot travel tools.
- Lottery application and results countdowns with UTC or local-time display.

### [Questionable Retainer](https://github.com/baanderson40/QuestionableRetainer)

Coordinates Questionable questing with AutoRetainer and Ocean Fishing:

- Pauses questing for ready retainer and deployable work.
- Optional Ocean Fishing handoffs through WahTools Feesh and Lifestream.
- Returns to the original character and resumes the saved quest after handoffs.
- Recovery controls for interrupted handoffs.

### [Retainer Repricer](https://github.com/baanderson40/Retainer-Repricer)

Automates retainer marketboard management:

- Reprices existing listings and lists new items.
- Uses Universalis data and configurable undercutting.
- Smart Sort for sell-list organization.
- Per-retainer repricing and selling controls.
- Sell List management and inventory context-menu support.
- In-game overlay, commands, and log viewer.

### [Tomes & Tides](https://github.com/baanderson40/TomesAndTides)

Coordinates weekly-capped tomestone farming:

- Tracks current-period farming targets and progress.
- Runs dungeons through AutoDuty.
- Optional AutoRetainer handoffs between dungeon runs.
- Dashboard and read-only diagnostic tools.

### [Unbroken Helper](https://github.com/baanderson40/unbroken-helper)

Provides automation and inspection tools for the Crucible of the Unbroken:

- Board-route selection and movement automation.
- Familiar rosters and route-specific combat configuration.
- Combat and recovery item handling.
- Debug scanners and game-state inspection tools.

### [Waitingway](https://github.com/baanderson40/Waitingway)

Displays FFXIV timers in the server info bar:

- Ocean Fishing registration countdowns.
- AutoRetainer airship, submersible, and retainer venture timers.
- Custom daily timers using local or Eorzea time.
- Configurable chat, toast, and popup completion notifications.

### [Yet Another FATE](https://github.com/baanderson40/Yet_Another_FATE)

Automates participation in active FATEs:

- Selects FATEs and travels to them.
- Coordinates movement and combat providers.
- Configurable travel and combat settings through `/yafate`.
